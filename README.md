# SQL Practice — Expense Tracker

Practicing core SQL fundamentals by building a small database and writing queries against it.

## What it covers
- Creating a database and table
- Inserting data
- Filtering with WHERE
- Sorting with ORDER BY
- Aggregating with GROUP BY and SUM

## Tool used
MySQL Workbench

## Usage
Run the commands in expenses.sql against a MySQL server to recreate the database and try the queries yourself.

## Notes
First SQL project — practicing the same data analysis concepts as my earlier pandas project, but using a real database.
